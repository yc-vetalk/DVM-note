# 藥品索引.html 更新流程

## 為什麼藥品索引是獨立的一步

`DVM-note/大三/獸醫藥理學/藥品索引.html` 是跨頁彙整所有藥物的總表，設計成「像藥典一樣，看索引表就知道這個藥適用哪些臨床症狀、為什麼」。它跟主題頁是兩份不同的檔案，寫完主題頁不會自動更新索引——這是很容易漏掉的一步，漏了的後果是：頁面內容做得再完整，使用者打開藥品索引表，看到自己剛整理完的藥還是一排「—」，會覺得工作沒做完。

**每次新建或重寫一個主題頁之後，一定要回來更新這個索引表**，這件事跟寫頁面本身同等重要，不是可選的收尾動作。

## 表格結構（4 欄）

```html
<tr data-topics="{{主題名，跟頁面檔名去掉.html一樣，例如「鴉片類止痛藥」}}"
    data-search="{{藥名小寫}} {{中文/商品名}} {{主題名}} {{臨床應用文字}}">
  <td>{{藥名}}<div style="font-size:.8em; color:var(--fg-faint); margin-top:2px;">{{中文名/商品名，沒有就不加這個 div}}</div></td>
  <td style="font-size:.85em; color:var(--fg-faint);">{{機轉／標的：受體、酵素、通道層級的作用方式，短語即可}}</td>
  <td style="font-size:.85em;">{{臨床應用與原因：對應哪些臨床症狀、為什麼選這顆藥，關鍵警示用★}}</td>
  <td class="drug-locations"><a href="{{主題}}.html#{{錨點}}" class="drug-link">{{主題}}：{{該連結對應的臨床應用文字}}</a></td>
</tr>
```

常用藥（講義明確強調「首選」「最常用」等字樣）在藥名前加：
```html
<span class="tag tag-exam" style="padding:1px 8px; font-size:.75em;">常用</span>
```

同一個藥如果在頁面裡好幾個小節都出現，`drug-locations` 那格可以放多個 `<a>`，臨床應用欄用分號串起對應的多個說明。同一個藥如果橫跨多個主題頁（例如 Apomorphine 同時在腸胃道用藥當催吐劑、在鴉片類止痛藥當個別藥物介紹），`data-topics` 屬性可以空格分隔寫多個主題名，但**機轉／標的那一格只有一個**（因為一列只有一組 td），填的時候選這個藥「最核心」的機轉描述，不用每個主題各寫一次。

## 新增一批藥物列的具體步驟

1. **先看頁面實際寫了哪些藥**：`grep -o 'id="drug-[a-zA-Z0-9]*"' {{主題}}.html`，這些 h3 錨點大致對應值得收進索引的藥物/概念。
2. **檢查索引表目前有沒有這個主題的列**：`grep 'data-topics="[^"]*{{主題}}[^"]*"' 藥品索引.html`。
   - 如果完全沒有列，代表是全新主題，要新增。
   - 如果已經有列但機轉欄是「—」，代表這個主題之前已經被別人（或你自己）机械地加過骨架，只需要補機轉欄——這種情況用 `scripts/fill_drug_index.py` 就好，不用重寫整列，見下方「只補機轉欄」。
   - 如果連骨架都沒有，才需要手寫完整的新 `<tr>`。
3. **新增列時，維持表格原本的字母序**（藥名的英文字母排序），找到該插入的位置插進去，不要全部堆在最後面，不然表格會失去可讀性。
4. **寫完後務必跑 `scripts/verify_page.py` 檢查 `<table>`/`<tr>` 開合數沒有跑掉**，這個表格單一檔案裡有兩三百列，手動編輯最容易在某一行漏改到 `<td>`/`</tr>` 導致後面全部跑版，光用眼睛掃很難發現。

## 只補機轉欄（最常見的情境）

這是目前最常見的情境：主題頁重寫完了，索引表的骨架列（藥名／臨床應用／連結）已經存在，只有機轉欄還是「—」。

1. 用這個指令把該主題所有列的 `data-search` 原文抓出來：
   ```bash
   grep -o 'data-search="[^"]*"' 藥品索引.html | grep {{主題}}
   ```
2. 針對每一筆，寫一句機轉/標的的短語（通常是「受體名稱＋致效/拮抗」或「酵素/通道＋作用方式」這個等級的濃縮，不用寫成完整句子）。範例：
   - `"μ opioid receptor agonist（高效力、高脂溶性）"`
   - `"GABAA受體致效劑（Barbiturate類，超短效）"`
   - `"Amide類，阻斷電壓門控Na⁺通道；高濃度IV可阻斷心肌Na⁺通道（抗心律不整）"`
3. 把這些寫成一份 JSON（key 是上面抓到的 `data-search` 原文整串，value 是機轉文字），存到暫存檔，然後跑：
   ```bash
   python3 .claude/skills/vetpharm-note-builder/scripts/fill_drug_index.py \
     DVM-note/大三/獸醫藥理學/藥品索引.html /tmp/mech_{{主題}}.json
   ```
4. 腳本執行完會回報「填入幾筆」「已經有內容跳過幾筆」「JSON 裡有但找不到對應的 key」——後者通常是原文複製打錯字或多打/少打一個空格，回去對一下 grep 結果修正。
5. 收尾用 `verify_page.py` 確認 `<table>` 沒有跑版。

## 常見錯誤

- **只取藥名當 key、不取整串 data-search**：某些藥名（例如 methohexital、thiopental）會同時出現在兩個不同主題的 cross-listed 列裡，只取藥名當 key 會兩邊搞混，正確做法是把整串 `data-search` 屬性文字都當 key。
- **忘記某個藥橫跨兩個主題頁時，索引表其實只有一列不是兩列**——不要因為在兩個主題頁都看到同一個藥，就以為索引表也要新增兩列。
- **機轉欄寫成臨床適應症而不是機轉**：機轉欄跟臨床應用欄是分開的兩件事，機轉欄要回答「這顆藥在分子/受體層級做了什麼」，不是「這顆藥治什麼病」——後者是第三欄的事。
