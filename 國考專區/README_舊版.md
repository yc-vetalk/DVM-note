# 國考題庫（獸醫師）

來源：考選部「考畢試題查詢平台」（wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx），類科＝獸醫師。只收題目與官方答案，**沒有詳解**。

## 目前內容
| 位置 | 說明 |
|---|---|

## 注意事項
- 官方答案缺：**100 年第一次**（考選部答案清冊抓不到）、**115 年第二次**（標準答案清冊尚未列出獸醫傳染病學）。這兩份檔內標示「尚未取得」。
- 97–99 年試卷自帶答案標記，100 年起答案取自考選部「標準答案更正清冊」；「一律給分」、「答 X 或 Y 均給分」會寫在該題的官方答案旁。
- 含圖題（約 157 題，如寄生蟲卵、魚病病理圖）只有文字，題目下方標示原卷頁碼。
- 文字由 PDF 直接擷取（非 OCR），已把康熙部首字（如 ⽣、⼤）轉為一般字；少數亂碼字元以 □ 表示，需對照原卷。
- 豬病學彙整是**關鍵字自動篩選**，可能漏題或誤收（如題幹未提「豬」但考豬病）；完整題目以 `獸醫傳染病學/` 為準。
- 公共衛生學、病理學等其他科目也有豬相關題，目前未收。

## 之後做禽病學／反芻動物學／魚病學
1. 在 `讀書筆記/scripts/exam_scraper/species.py` 的 `SPECIES` 新增一組（`strong` 題幹關鍵字、`weak` 選項關鍵字、`diseases` 疾病分組），例如 `'禽病學'`、`'反芻動物學'`、`'魚病學'`。
2. 在 `scripts/exam_scraper` 資料夾內準備好資料（`q.py` 查詢清單、`meta.json`、`pdf/`、`answers.json` 等，流程見該資料夾腳本），執行 `.venv/bin/python 讀書筆記/scripts/exam_scraper/make_md.py 讀書筆記/國考題庫`。
3. 魚病學題目在 102 年等試卷中有不少圖題（見上方注意事項）。
