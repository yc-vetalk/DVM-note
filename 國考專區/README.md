# 國考專區（資料）

獸醫師國家考試的**原始資料與整理用資料**都放這裡。網站上給人讀的頁面在 `DVM-note/國考/`（統整頁、統整表格、跨科專題），由這裡的資料產生。

來源：考選部「考畢試題查詢平台」（wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx），類科＝獸醫師。只收題目與官方答案；詳解是整理者依知識寫的，不是官方詳解。

---

## 1. 分類方式：先選「考科」或「課程」

```
國考專區/
├── README.md                     ← 本檔
├── README_舊版.md                ← 搬遷前的說明（保留參考）
├── 考科/                          ← 官方試卷，一個考科一個資料夾
│   ├── 獸醫傳染病學/
│   │   ├── 試卷/                 ← 每份試卷一個 md（97-1.md … 115-2.md，共 32 份、2560 題，含官方答案）
│   │   └── 原始試卷/             ← 考選部原始 PDF（含圖題請對照這裡）
│   └── 公職高考三級_傳染病與公共衛生學(申論)/
│       └── 原始試卷/             ← 只下載、尚未整理
└── 課程/                          ← 從考題整理給某門課用，一門課一個資料夾
    ├── 豬病學/
    │   ├── 國考題彙整.md         ← 從傳染病學篩出的豬相關題，依疾病分組
    │   ├── 詳解/                 ← 逐選項詳解原稿（s0.txt …）
    │   └── 自我測驗/             ← 自我測驗題庫原稿（week…py）
    └── 禽病學/（同上結構）
```

- **考科**：官方的、依考選部科目分。新增一科（例如獸醫公共衛生學）就加一個資料夾，裡面一樣放 `試卷/`、`原始試卷/`。
- **課程**：衍生的、依你上的課分。新增一門課（例如反芻動物疾病學）就加一個資料夾，裡面放 `國考題彙整.md`、`詳解/`、`自我測驗/`。
- 工具程式不放這裡，在 `讀書筆記/scripts/exam_scraper/`；考選部下載的工作資料在該處的 `workdir/`。

## 2. 資料的已知限制（頁面上也要寫明）

- **官方答案缺**：100 年第一次、115 年第二次（考選部答案清冊抓不到）。
- **一律給分**、**試題更正**（98-2#18、99-2#11，寫在 `make_md.py` 的 `OVERRIDE`）。
- **含圖題**約 157 題只有文字，題目下方有原始 PDF 路徑與頁碼。
- 文字直接從 PDF 擷取（非 OCR）；少數亂碼字元以 □ 表示。
- 課程彙整是**關鍵字自動篩選**，可能漏題或誤收；完整題目以 `考科/…/試卷/` 為準。
- 其他五科（病理、藥理、實驗診斷、普通疾病、公共衛生）**尚未下載**，只有連結在 `workdir/rows_all.json`。

## 4. 之後出問題時，先檢查這些

1. **腳本說找不到檔案**
   - 打開 `讀書筆記/scripts/exam_scraper/paths.py`，確認 `LAYOUT` 是 `'new'`（新位置）。
   - 臨時要用舊位置可設環境變數：`EXAM_LAYOUT=legacy`（但舊位置已經沒有資料，除非已還原）。
   - 確認是從 repo 根目錄（`上群/`）或 `workdir/` 執行；`paths.py` 已改成絕對路徑，任何位置執行都應該找得到。
2. **舊資料夾 `讀書筆記/國考題庫/` 又冒出檔案**
   - 代表有對話框還在用舊路徑寫入。把那些檔案移到上表的新位置（注意是否和新位置的檔案重複，重複時比較內容再合併），並提醒那個對話框改用新路徑。
3. **指引裡的指令跑出錯的結果**
   - 指引已改成新路徑；若看到 `讀書筆記/國考題庫/…` 或 `make_md.py ../../../國考題庫` 這類舊寫法，是沒更新到的地方。`make_md.py` 現在**不要給輸出資料夾參數**，它會依 `paths.py` 寫到正式位置。
4. **自我測驗或國考統整頁的內容不對**
   - 重跑一次產生流程，輸出到暫存資料夾，再和網站上的檔案 `diff -r` 比對，找出差在哪。
   - 指令範例：`QZOUT=/tmp/qz SUBJECT=豬病學 .venv/bin/python 讀書筆記/scripts/exam_scraper/build_quiz.py`，再 `diff -r /tmp/qz DVM-note/大四上/豬病學/自我測驗/data`。
5. **想確認搬遷沒弄丟東西**
   - `git log --stat` 看 2026-10-23 的搬遷 commit（commit 後），或比對檔案數：`考科/獸醫傳染病學/試卷/` 應有 32 份 md、`原始試卷/` 32 份 PDF；`課程/豬病學/詳解/` 11 份、`自我測驗/` 10 份；`課程/禽病學/詳解/` 9 份、`自我測驗/` 12 份；公職申論 `原始試卷/` 41 份。
6. **要整個退回舊位置**
   - 依上表反向搬回 `讀書筆記/國考題庫/`，把 `paths.py` 的 `LAYOUT` 改回 `'legacy'`，再重跑 `make_md.py` 讓含圖題路徑變回舊寫法。先在暫存資料夾試，確認輸出一致再動正式檔案。
