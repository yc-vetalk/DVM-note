# 講義整理成網頁筆記：給其他對話框的完整指引

> 使用方式：使用者會把這份文件丟給新的對話框，再附上一份講義 PDF。讀完這份文件，你應該能做出跟主線對話框同等品質的網頁與知識整理。
> 適用範圍：`DVM-note/` 的課程週次筆記（大四上、大三）與總複習主題頁。藥理學有自己的 skill（`.claude/skills/vetpharm-note-builder`），上群AH 有 `ah-guideline-builder`，那兩條線以各自的 skill 為準，但本文的「內容品質」原則同樣適用。
> 最後更新：2026-10-22（加入講義 md【含圖】規則、`scripts/course_tools/` 通用腳本、補充說明提示框位置）

## 0. 開工前一定要做的事

1. **讀 `CLAUDE.md`**（會自動載入）：站台結構、兩種頁面樣式、新增頁面要更新哪些檔案，都寫在那裡，本文不重複。
2. **讀 `_worklog.md` 最上面幾筆與「待交接」**：看其他對話框最近改了什麼，避免覆蓋。
3. **讀兩份範本頁的原始碼**，這是品質標準，不確定某個元件怎麼寫就照抄它們：
   - `DVM-note/大四上/獸醫臨床及影像診斷學/week07_犬貓完整口腔評估與治療COHAT.html`：圖很多的技術類講義（101 張圖、兩個互動元件、分級表）。
   - `DVM-note/大四上/禽病學/week08_馬立克病.html`：疾病類講義（大方向區塊、鑑別表、考試方向、臨床情境題）。
4. **記住使用者是誰**：獸醫系學生，同時是動物醫院的住院醫師。筆記要同時服務兩件事：**國考與期中考**、**臨床實際用得到**。文案用中性措辭，不要預設「實習生見習」的身份。

## 1. 核心原則（品質的底線，不可彈性）

| 原則 | 具體做法 | 為什麼 |
|---|---|---|
| **講義是主體** | 內容與章節順序跟著講義走。不要用自己的知識取代講義，也不要自己重新分類 | 考試考的是老師教的東西；使用者曾發現頁面是憑一般知識寫的，要求返工 |
| **講義以外的一律標「補充」** | 段落用小字 `<p style="font-size:.9em; color:var(--fg-muted);">補充：…</p>`，或在表頭／句中寫「（補充）」 | 使用者要能分辨哪些是老師說的、哪些是延伸 |
| **推論與考試方向標「推測」** | 「考試方向（推測）」整節；臨床推論寫「推測」或「看點（補充）」 | 曾經有頁面寫「國考常考」但沒有考古題根據，被要求刪掉。**沒有考古題就不能說「常考」** |
| **不犧牲內容** | 每段盡量一個螢幕看完（約 840 px 高），但放不下就讓它超出或拆兩段；會影響臨床決定的內容不能收進「點開才看」 | 使用者明確說過「不要犧牲內容，超出也沒關係」 |
| **疾病名稱** | 標題、表頭、第一次出現：「中文（English, ABBR）」，例如「網狀內皮增生症（Reticuloendotheliosis, RE）」 | 使用者的固定要求 |
| **藥物一定寫途徑** | 只要有明確途徑（PO／IV／IM／SC／局部注射／外用／OTM…）就寫出來，不能只寫劑量或藥名 | 使用者的固定要求 |
| **有參數就要解釋** | 表格裡的數字、儀器參數、分級切點，旁邊要有一個框或一句話說明「這個數字代表什麼、為什麼是這個值」 | 使用者說過「有參數的請幫我解釋」 |
| **不憑印象寫數字** | 劑量、切點、百分比只能來自講義或你在這次對話真的讀到的資料 | 數字錯了比沒寫更糟 |
| **圖片要附** | 見第 5 節 | 講義很多資訊只在圖裡 |

## 2. 工作流程

```
讀講義文字 → 看縮圖總覽 → 定大綱 → 擷取圖片 → 寫頁面 → 驗證 → 更新索引 → 寫日誌 → 回報
```

### 2.1 讀講義

```bash
# 抽文字（含頁碼標記，之後引用頁碼用）
./.venv/bin/python - <<'EOF'
import pymupdf
d = pymupdf.open("講義.pdf")
with open("/tmp/raw.txt", "w") as f:
    for i, p in enumerate(d):
        f.write(f"=====PAGE {i+1}=====\n{p.get_text()}\n")
EOF
```
暫存檔放你的 scratchpad 目錄，不要放在 repo 裡。

**講義文字存成 md（省 token）**：整份抽完後，另存到 `讀書筆記/講義文字/<科目>/<編號>_<主題>.md`（逐頁 `## p.N`）。**凡是有圖片、圖表或表格圖的頁面，都要加一行「【含圖】本頁有…，md 只有文字，請回看原 PDF：<路徑> 第 N 頁」**（判斷：圖片面積佔頁面 2%–95%，或向量繪圖數比該份中位數多 5 以上）。看過圖的頁面可再加「【看圖補記】」一句摘要。之後讀 md 時，遇到【含圖】頁要回看 PDF，不能只靠文字。

**文字一定要整份讀完**。很多投影片幾乎沒有文字（標題＋照片），所以第二步一定要看圖：

```bash
./.venv/bin/python DVM-note/_scripts/pdf_contact_sheet.py "講義.pdf" <scratchpad>/sheets
```
每 12 頁拼成一張總覽，用 Read 工具逐張看。字太小、表格是圖片的頁面（例如藥物表、症狀表），再單獨用 pymupdf 以 160 dpi 輸出那一頁來讀。**每一頁都要看過**，才知道哪些頁是重點、哪些圖要放。

### 2.4 寫頁面

- 複製範本頁，保留 `<head>`、`<header>`、`showSection`／`SECTION_NAMES`／搜尋腳本那一段，換掉 `<title>`、pagehead、TOC 與 `<main>` 內容。

### 2.6 更新索引（照 CLAUDE.md「新增一週筆記時」）

1. 科目 `index.html`：加 door（或把 `.door.pending` 換成連結）。
2. 頂層 `DVM-note/index.html`：該科目卡片的 topics 清單。
3. `DVM-note/assets/nav-data.js`：該科目 desc。
4. `DVM-note/search-index.js`：**每一節一筆**（subject／semester／week／weekTitle／url／section／sectionName／keywords／snippet），keywords 中英文都放（疾病中英全名、縮寫、藥名、病原、關鍵數字），snippet 一兩句濃縮該節。全站搜尋視窗（`assets/spotlight.js`）會同時搜這些欄位與自動產生的全文索引 `search-fulltext.js`；手寫 keywords 命中時排序較前、摘要也比較好讀，所以仍要認真寫。頁面改完後跑 `python3 DVM-note/_scripts/build_search_fulltext.py` 重建全文索引（commit 時 hook 也會自動跑）。插在同科目最後一筆之後。

這些是多對話框共用檔案：**讀、改、寫在同一次 Python 執行內完成**，並用 `assert` 確認錨點文字只出現一次、新內容還不存在。

### 2.7 寫日誌、回報

- `_worklog.md` 最上面新增一筆（時間用 `date '+%Y-%m-%d %H:%M'`）。
- **不要 commit、不要 push**，除非使用者明確要求。
- 回報格式見第 9 節。

## 3. 大綱怎麼寫

### 3.1 固定骨架

```
1   重點摘要（大方向區塊 ＋ 主線流程 ＋ 補充說明提示）
2…N 講義本體：照講義順序，一個大主題一節
N+1 鑑別比較（講義有多個疾病／方法時）
N+2 考試方向（推測）
N+3 學習重點整理（選用：內容很多時放 8–12 條考前速讀）
N+4 練習題
```

### 3.2 怎麼切節

- **一節 = 講義的一個大主題**，通常對應講義的一個章節標題或一組連續投影片。一份講義通常 10–15 節。
- 講義每頁重複出現的目錄頁（例如 COHAT 每一步都重放一次八步清單）是**切節的訊號**，不要當內容抄。
- 內容太少的相鄰步驟可以合併（COHAT「第二、三步」合成一節），太多的拆開（COHAT 第六步拆成「拍攝」與「品質與判讀」）。
- 講義本身很零散、需要重排時，**先跟使用者說你打算怎麼排**，不要默默改。

### 3.3 標題寫法

- 節標題：`中文 English`，例如「牙周病是什麼 Periodontal Disease」「診斷 Diagnosis」。
- 節內 `<h3>` 後面加重要度標籤：

```html
<h3>齒式 Dental formula<span class="lv lv-must">必考</span></h3>
```

| 標籤 | 用在什麼內容 |
|---|---|
| `lv-must` 必考 | 定義、分級切點、數字、鑑別要點、講義反覆強調或放大字的內容、流程順序 |
| `lv-know` 理解 | 機轉、原理、為什麼要這樣做；懂了就會寫，不必逐字背 |
| `lv-skim` 看過 | 歷史、設備細節、發生率的出處、環境準備 |

### 3.4 左側 TOC

用 `section-label` 分組（例如「總覽／基礎／COHAT 八步／病例與複習」），`nav-icon` 可以用數字或單一 emoji。每個 `<a>` 的 `onclick="showSection('id')"` 要對應 `id="section-id"`。

## 4. 摘要怎麼寫（第 1 節）

第 1 節是整頁最重要的一節：使用者考前可能只看這一節。

### 4.1 大方向區塊（必備）

```html
<div class="overview">
  <div class="overview__title">這堂課的大方向</div>
  <dl>
    <dt>這是什麼（病／技術）</dt>
    <dd>一兩句話定義，含病原或核心概念。</dd>
    <dt>為什麼重要</dt>
    <dd>流行率、經濟或臨床衝擊、法規地位（例如法定傳染病）、跟其他病的關係。</dd>
    <dt>這章要抓的重點</dt>
    <dd><ol>
      <li><a href="#section-xxx">重點名稱</a>：一句話講清楚，關鍵詞加粗。</li>
      …（5–9 條，每條連到對應的節）
    </ol></dd>
    <dt>容易混淆</dt>
    <dd>學生最常搞混的 2–4 組概念，直接寫出正確分法。</dd>
  </dl>
  <div class="lv-legend">（照範本頁複製）</div>
</div>
```

`dt` 的名稱可以依講義調整（「這是什麼病」「這章在講什麼」「COHAT 是什麼」），但「是什麼、為什麼重要、重點、容易混淆」這四個方向要有。

### 4.2 接在大方向後面

- **主線流程**（選用）：講義有步驟或因果鏈時，用 `.flow` 畫出來，下面可附一句記法（標「補充」），例如「看、麻、監、探、洗、照、治、家」。
- **講義原本的 Summary**（如果講義有）：用 `alert-info` 照講義列出。
- **補充說明提示**（必備）：一個 `alert-warn`（label「補充說明」），放在大方向區塊（含 lv-legend）正後方，說明「標補充的不是講義內容（含讀書補充Note）、標推測的不是考古題、考試以老師上課為準、圖片為老師講義截圖」。

## 5. 圖片規則

### 5.1 能不能公開

| 來源 | 處理 |
|---|---|
| **老師的課程講義** | 使用者已多次表示可以公開：放在 `img/<主題>/`，**不要 gitignore** |
| **商業教科書、付費教材的頁面截圖** | **只留本機**：放在已被 gitignore 的位置（例如 `DVM-note/Textbook/**/img/`），不能出現在公開網站上 |
| 不確定 | 先問使用者 |

### 5.2 放哪些圖

- 使用者要求「圖片都要附」時：**有照片、X 光、示意圖、表格圖的頁全部放**；只略過純文字頁（文字已經寫進網頁）、講者簡介、謝謝聆聽頁。
- 優先**整頁截圖**，保留原本的箭頭與標籤；不要硬裁出乾淨照片。
- 文字很小的表格頁：改寫成 HTML 表格（比圖好讀，也搜得到），圖可以不放。
- 圖要插在對應文字段落**之後**，不要全部堆到節末。兩張相關的圖用 `<div class="grid-2">` 並排，三張用 `grid-3`。

### 5.3 圖說怎麼寫

```html
<div class="figure"><img src="img/<主題>/ch_p057.jpg" alt="口鼻廔管" loading="lazy">
  <div class="figure-caption">口鼻廔管（oronasal fistula）：在上顎犬齒的腭側探查或沖水。</div>
  <div class="figure-source">來源：課程講義 p.57</div></div>
```

- 圖說要回答「**這張在看什麼**」：看到的構造、病變、箭頭指的東西，而不是只重複投影片標題。
- 講義沒有文字、你也看不出確切內容時，**照實寫**「講義此頁無文字說明」，不要編。
- 每張圖都要有 `figure-source` 頁碼。

## 6. 細節怎麼寫（第 2…N 節）

### 6.1 每一節的結構

```
section-head（編號＋標題）
section-desc：一兩句話說這節在解決什麼問題
h3 小主題 ＋ lv 標籤
  內容（表格／flow／清單／卡片）
  對應的圖
  補充小字
footer.note-footer：資料來源（講義頁碼）＋免責聲明
```

### 6.2 用哪種元件

| 內容 | 元件 |
|---|---|
| 兩個以上東西的比較（疾病、方法、物種、分級） | `.table-wrap > table`，**優先使用** |
| 機轉、因果鏈、操作步驟 | `.flow`（`flow-node` ＋ `flow-arrow`） |
| 兩三個並列概念 | `.grid-2`／`.grid-3` 裡放 `.card` |
| 重點 | `alert-success`（重點、黃金準則、記法） |
| 補充資訊 | `alert-info` |
| 注意、副作用 | `alert-warn` |
| 禁忌、危險 | `alert-danger` |

alert 內部一律用文字標籤 `<div class="alert-label">注意</div>`，不用 emoji。

### 6.3 寫出「使用者讀得懂」的解釋

- **不要只翻譯講義**。講義的條列很精簡（「G2：探查時有出血」），網頁要補上「所以 G1 和 G2 的分界就是探查會不會出血」這種把重點點破的句子。
- **數字切點集中、對齊**：分級表每一級一列，把切點加粗；接著給一句記法（例如「0.2 → 0.5 → 1 mm 三個切點；能上下動直接是 M3」）。
- **反直覺的地方要講出來**：例如「垂直於牙齒會延長、垂直於感應器會縮短」，或「大魔王是細菌，不是結石」。
- 講義用的原文術語保留英文，第一次出現加中文。

## 7. 對應臨床重點

住院醫師身份代表筆記要能直接用在病患身上。每個疾病或技術，至少回答下面其中幾題：

| 問題 | 寫法 |
|---|---|
| 看到什麼要想到它？ | 主訴、症狀、理學檢查發現（例如「單側流鼻水 → 想到口鼻廔管」） |
| 下一步做什麼？ | 檢查順序、要拍什麼、要抽什麼 |
| 怎麼跟其他病分開？ | 鑑別表（年齡、病變位置、檢驗） |
| 怎麼處置？ | 藥物＋途徑＋劑量（只寫講義有的或你真的查到的），操作要點 |
| 常見陷阱？ | 正常變異被誤判（例如 Chevron effect、頦孔）、操作危險（彈簧式開嘴器） |
| 飼主衛教？ | 術後照顧、居家保健、預後 |

- 講義有病例時：列出講義給的資料，再寫一個「看點（補充）」框，把病例連回前面的章節。講義只有照片沒有分析，就明說「講義沒有文字分析」。
- 講義沒提、但臨床上很重要的東西可以補，**一定標「補充」**，並且簡短，不要喧賓奪主。
- 有劑量時，在練習題放一題**劑量換算**（mg/kg → mg → mL），讓數字變成會用的知識。

## 8. 對應國考與期中考

### 8.1 考試方向（推測）節

```html
<div class="alert alert-warn"><div class="alert-label">注意</div>
  <p>以下是依講義強調的內容<strong>推測</strong>的出題方向，不是考古題，考試範圍以老師上課為準。</p></div>
<div class="table-wrap"><table>
  <thead><tr><th>可能考法</th><th>答題重點</th></tr></thead>
  …（10–12 列；答題重點寫成可以直接抄到考卷上的關鍵詞）
</table></div>
```

**判斷什麼會考**（依講義本身的線索）：講義有編號清單、分級、數字切點、比較表、「重要」「必須」「禁用」字眼、反覆出現的內容、老師標黃或放大字。

### 8.2 考古題

- 使用者提供考古題之前：**不可以**寫「國考常考」「歷屆必考」。
- 拿到考古題之後：可以把對應的考點標成「考古題出現過（年份）」，這是有根據的說法。

### 8.3 跨講義一致

同一科的鑑別表（例如禽病的 AI／ND／IB／ILT，或 MD／LL／RE）在不同頁要一致。兩份講義說法不同時，兩種都列出並註明各自出處，不要自己選一個。

## 9. 練習題

- 數量：**12–15 題**。題型混搭：選擇題 6–8、是非題 1–3、簡答題 1–3、**臨床情境題 2–3**。
- 每題答案一律收在 `<details class="quiz-reveal"><summary></summary>…</details>`，預設隱藏。
- 解析要說明**為什麼其他選項錯**，不是只給答案。**每個選項都要寫理由**（對的也要說為什麼對），不能只寫「(B) 對。(A)(C)(D) 錯。」；能標講義頁碼就標，講義以外標「補充」。從別頁沿用的舊詳解如果只有結論，要補上理由再用（使用者 2026-10-29 明確要求）。
- 臨床情境題結構：一段病例（物種、年齡、體重、主訴、檢查發現）＋(1)(2)(3)(4) 子題，涵蓋「辨認 → 檢查 → 處置（含劑量計算）→ 衛教」。
- 是非題可以故意放常見誤解（例如「規則 V 形透亮區是根尖病變」）。

## 10. 可以發揮的空間

下面這些不是每頁都要有，看講義內容決定。做得好會讓頁面明顯更好用：

| 類型 | 例子 | 什麼時候做 |
|---|---|---|
| 計算機 | ICPI 計算（新城病頁）、PD 分級判定（COHAT 頁） | 講義有公式或多條件分級 |
| 篩選器 | 依症狀篩選疾病（寵物鳥病毒病頁） | 多個疾病、症狀重疊 |
| 時間軸 | 鋇劑造影時間軸（消化道影像頁） | 有時間順序的影像或病程 |
| 互動示意圖 | X 光角度與影像長度（COHAT 頁）、蹄病病灶位置圖（牛蹄病頁） | 空間或幾何概念，文字很難講清楚 |
| 記法 | 口訣、數字規律 | 要背的清單、數字 |
| 跨頁連結 | 一行小字連到別頁已講完整的概念 | 內容在別頁已經有，不要整段複製 |

互動元件的寫法：頁面專屬的 `<style>` 與 `<script>` 放在 `</main></div>` 之後、`showSection` 腳本之前，用 IIFE 包起來；顏色用 `var(--accent)` 等 CSS 變數，並為深色模式（`html[data-theme="dark"]`）調整。

**不能發揮的**：第 1 節列的原則、講義的章節順序、數字的來源、補充與推測的標註。
