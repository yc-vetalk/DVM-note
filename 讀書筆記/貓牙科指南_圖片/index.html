1．牙周病分期（PD0–PD4）

分期依據是「附著喪失（attachment loss）」比例，只能靠探診或 X 光測量，肉眼只能看到牙齦與牙結石——所以每張圖的原文圖說都強調 radiographs are required。

分期定義（指南原文）
PD0臨床正常，無牙齦發炎或牙周炎
PD1只有牙齦炎，無附著喪失；齒槽緣高度與結構正常
PD2早期牙周炎：附著喪失 <25%，或多根齒最多 stage 1 根分岔暴露
PD3中度牙周炎：附著喪失 25–50%，或 stage 2 根分岔暴露
PD4重度牙周炎：附著喪失 >50%，或 stage 3 根分岔暴露

3．咬合不正（Malocclusion）

分類來源描述常見創傷位置
MAL1牙齒上下顎關係正常，個別牙齒排列異常下犬齒舌側位 → 戳傷上顎
MAL2骨骼下顎後縮（overbite）下犬齒戳傷上顎
MAL3骨骼下顎前突（underbite）輕度：上第三門齒與下犬齒互磨；重度：上門齒傷及下門齒舌側牙齦
MAL4骨骼頭尾向、左右或背腹向的不對稱左右型：上 P4 撞傷下 M1 頰側黏膜

5．牙齒吸收（Tooth Resorption）

這組是整份指南判讀價值最高的圖。分型要看 X 光，而分型直接決定處置：拔除整顆牙，或只切除牙冠。

分型X 光特徵處置
Type 1（發炎性）牙體局部缺損，其餘牙根放射密度正常，牙周韌帶腔（PDL space）清楚完整；常合併牙周炎整顆拔除（含牙根），術後照 X 光確認拔乾淨
Type 2（置換性）牙根被骨頭取代：PDL space 消失，殘根變得較透亮、呈條紋狀牙冠截除（crown amputation／coronectomy）＋牙齦縫合，術後 X 光記錄刻意保留的牙根
Type 3同一顆牙同時有 type 1 與 type 2 特徵雙根齒：type 1 的根拔除、type 2 的根截冠；單根齒（如犬齒）：盡量拔，必要時在較根尖處截除

7．口腔腫塊

貓的口腔病灶高達 68% 是惡性，最常見的是鱗狀上皮細胞癌（SCC）。指南特別提醒：如果只有單一區域出現牙齦炎和附著喪失（focal periodontitis），要認真考慮底下是腫瘤。可疑病灶都要做切片。

10．局部神經阻斷

神經阻斷是多模式止痛的關鍵，可以穩定麻醉、銜接術後止痛。指南提醒：貓的眶下管平均只有約 3 mm 長（與頭型無關），進針要非常小心，注射前一定要回抽確認沒有抽到血。有研究比較眶下法（針不進眶下管）與經皮上顎尾側法，注射物的分布沒有顯著差異。
