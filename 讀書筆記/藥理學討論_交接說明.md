- 練習題要包含**臨床情境題**（一段病例加上 (1)(2)(3) 小題），答案先不要給，等我作答。

## 思考方式（請沿用這套框架）

### 1. 受體在哪裡，就決定副作用在哪裡
同一個受體常分布在好幾個器官。藥物擋了一處，另一處也會受影響。所以每講一個藥，都要問：
**作用在哪個受體 → 這個受體還在哪些器官 → 所以會有什麼連帶影響 → 所以哪些病患禁用。**

例子：Metoclopramide 擋 D2。
- CTZ 的 D2 → 止吐
- 腸道的 D2 → 放開蠕動的煞車
- 腦部的 D2 → 錐體外症狀、癲癇閾值下降 → **癲癇犬避免使用**

Domperidone 不會通過血腦屏障（BBB），所以沒有中樞副作用。

### 2. 找「最終共同路徑」
多條訊號匯到同一個終點時，擋終點的藥最廣效。
- **嘔吐**：前庭、CTZ、迷走神經傳入三條路，最後都匯到嘔吐中樞的 NK1 → Maropitant 最廣效。其他止吐藥只擋其中一條路，要依病因選藥。
- **胃酸**：H2、M3、Gastrin 三條路，最後都匯到 H⁺/K⁺-ATPase → PPI 最強。PGE（EP3）是唯一的煞車 → NSAID 把煞車拿掉。

### 3. 油門與煞車
把生理系統拆成「油門」和「煞車」，藥物不是踩油門就是放煞車。以腸道蠕動為例：
- 執行者：ACh 作用在 M3
- 油門：5-HT4、Motilin、抑制乙醯膽鹼酯酶（AChE）
- 煞車：D2、μ-opioid、α2

### 4. 共病與禁忌對照
問「這隻動物還有什麼病，所以不能用什麼藥」。用表格整理：「共病 → 避免的藥 → 原因（回到受體或代謝）」。常見例子：
- 癲癇 → Metoclopramide、Acepromazine
- 慢性腎病（Chronic Kidney Disease, CKD）→ 腎排除藥物需減量（Famotidine；CKD 貓的 Mirtazapine 改隔天給）
- 脫水 → 滲透性瀉劑
- 懷孕 → Misoprostol
- 青光眼 → 抗膽鹼藥
- 感染性腹瀉 → Opioid 止瀉藥
- 貓 → Bismuth subsalicylate（含水楊酸）

### 5. 交互作用從「代謝」和「吸收」兩條線想
- **代謝**：CYP450 抑制劑（Cimetidine、Omeprazole、Ketoconazole）會讓其他藥濃度上升，例如 Cisapride 配 Azole。
- **吸收**：螯合（Sucralfate、制酸劑配 Fluoroquinolone、Tetracycline）→ 間隔給藥。胃 pH 上升 → Azole 抗黴菌藥、鐵劑吸收下降。

### 6. 物種差異一定要講
犬、貓、反芻獸、馬的差異，常是考點也是臨床陷阱，例如：
- 貓用 α2 催吐，犬用 Apomorphine 催吐
- Ondansetron 口服生體可用率：犬低於 10%，貓約 32%
- Erythromycin 促蠕動：貓直接活化 motilin 受體，犬是間接作用
- 貓缺乏葡萄糖醛酸化（glucuronidation）能力 → NSAID、Acetaminophen 的毒性

### 7. 從臨床回推
我丟一張處方或一個病例時，請依序回答：
1. 每個藥的目的與機轉
2. 為什麼是這個組合，以及組合之間有沒有加乘或衝突
3. 這隻動物的共病有沒有禁忌
4. 要監測什麼

### 技術架構
- **網站形式**：純 HTML、CSS、JS 的靜態網站，不用框架。雙擊就能開，也可以用本機伺服器在手機上看。
- **位置**：`DVM-note/`，GitHub Pages 網址是 `https://yc-vetalk.github.io/DVM-note/`。
- **樣式**：共用 `assets/ah.css`。常用元件包括：
  - 結構：`.section`（編號章節）、`.card`、`.grid-2/3/4`
  - 表格：`.table-wrap > table`
  - 提醒框：`.alert-success／info／warn／danger`，裡面放文字 `.alert-label`
  - 流程：`.flow`（箭頭流程）、`.step`
  - 其他：`.figure`（圖片）、`<details class="quiz-reveal">`（隱藏答案的練習題）
- **頁面骨架**：藥理頁直接複製一份既有頁面（例如 `降血壓藥物.html`）當模板。結構是頂部 `pagehead` 加上 `pagewrap`，左邊是捲動高亮的目錄，右邊是內容。

### 新增或改寫一個藥理主題頁的步驟
1. **讀講義原文**：用 `extract_pdf_text.py` 抽出文字。圖多的投影片改用 `_scripts/extract_pdf_images.py` 轉成圖片來看。
2. **寫頁面**：
   - 第 1 節固定是「重點摘要」：綠框寫白話導覽，藍框條列國考與臨床重點。
   - 中間各節跟著講義的順序走。
   - 最後是練習題。
3. **教科書核對**：grep VPT10 或 HBK 的文字快取，只引用真的查到的內容。
4. **補充元素**（視需要加入）：
   - 結構式：用 `_scripts/draw_structure.py` 從 PubChem 取得結構，再用 RDKit 自己畫，不截教科書的圖。
   - 共病禁忌表、物種差異表、國考方向（推測）。
5. **驗證**：跑 `verify_page.py <頁面> --index 藥品索引.html`，會檢查三件事：
   - 標籤開合是否配對
   - 目錄和章節 id 是否對應
   - 索引錨點是否有效

   必須跑到印出「全部通過 ✓」。
6. **同步更新四處**：
   - `藥品索引.html`：新藥要新增一列，而且機轉欄要填實際內容。
   - `search-index.js`：每節一筆搜尋條目，改完用 `node -c` 檢查語法。
   - 科目首頁 `index.html`：更新卡片狀態。
   - `assets/nav-data.js`：更新頂部導覽的描述。
7. **用瀏覽器實測**：用無頭 Chrome 截圖檢查，手機寬度也要看，特別是表格與互動元件。
8. **寫日誌**：在 `_worklog.md` 記下改了什麼。

### 互動元件的做法（新點子可以照這個模式加）
以「受體地圖」（`腸胃道用藥.html` 第 2 節）為範本，一個互動元件就是一個**自給自足的 section**，包含四個部分：
1. **自繪 SVG 或 HTML 介面**：可點的區塊加上 `data-*` 屬性，例如 `data-loc="parietal"`。
2. **一個 JS 資料陣列**：內容放在陣列裡，改內容只需要改陣列，不用動版面。
3. **一小段 render 函式**：負責篩選並產生表格或卡片。
4. **局部 `<style>`**：class 用專屬前綴（例如 `gm-`），避免影響全站。要沿用 `ah.css` 的色彩變數（`--fg`、`--line`、`--bg-faint`），深色模式才會正常；手機寬度下表格要改成卡片版面。

以後可以套用同一模式的點子（只是舉例）：
- 其他系統的受體地圖：心血管、自主神經、中樞
- 共病選藥器：勾選共病 → 篩出要避免的藥
- 劑量計算器：急救流程頁已經有一個 CPR 劑量計算器可參考
- 藥物交互作用查詢
- 翻卡記憶模式：把練習題做成翻卡
- 個人註記：用 localStorage 存在自己的瀏覽器，例如藥名對照頁的「我的藥名」
