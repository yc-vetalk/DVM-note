## 3. 圖片：這門課的取圖與隱私

### 3.1 一般圖
- 講義多是投影片截圖，**生理與免疫兩份有大量示意圖與顯微／解剖圖**，必須配圖（講義整理指引）；用 `DVM-note/_scripts/pdf_contact_sheet.py` 做縮圖總覽**每頁都看**，再用 `export_slides_jpg.py` 或 `讀書筆記/scripts/imaging_tools/pdf_figures.py`（`list`／`embedded`／`crop`）取圖；圖說三層寫法與標注工具見 `讀書筆記/臨床及影像診斷學_製作指引.md` 第 2 節（組織切片、病例照片適用）。
- 整頁圖寬度 ≤ 1300–1600 px、單張盡量 < 400 KB；站上 `img/` 已很大，不要無限制加。
- 版權：**這三份（生理、骨骼、免疫）沒有署名，圖片可能來自網路或教科書**。講義圖截圖是否可公開**沒有使用者明確紀錄**（只有影診消化道講義、豬禽病學有確認）。**第一次放圖前先問使用者**，並在頁面「資料來源」寫講義檔名而非原始出處；不要猜測圖的原始出處。

### 3.2 病例照片頁（`Week1-4.pdf` p.55–66）
每頁是「檢體（金魚、龍虎班、錦鯉、泰國獅頭、石賓／馬口魚、莫瑞雪、黃金波羅、香魚、老鼠斑）＋外觀症狀」加寄生蟲或病原照片；其中有「複殖吸蟲亞綱（Digenea）」「體表白點」等。這些**看起來是教學病例，但也可能含真實案例資訊**：照片上若有院名、案號、日期，遮蓋後再放；整理成「症狀→可能病原→診斷」表時，**講義沒寫診斷結論的就寫「講義未列診斷」**，不要自己補病名（可標「補充，推測」）。

## 4. 內容規則（魚病特有）

- **疾病與病原名稱**：「中文（English, ABBR）」；蝦病、魚病學名斜體，如白點症病毒（White spot syndrome virus, WSSV）。考古卷英文病例的病名與病原都要**中英並列**，因為考試用英文。
- **水質數值與閾值**：只寫講義有的數字；講義沒寫的（例如某魚種的安全 DO 值）不要憑記憶補，要補就標「補充」並註明來源類型。pH 對 NH3 的影響、TAN 與 NH3 的關係、亞硝酸鹽（棕血症，血紅素被氧化、水中有氧魚仍缺氧）是講義強調的**因果鏈**，要用流程或表格講清楚，不要只列數字。
- **藥物／治療**：講義提到任何藥物或處置（例如治療白點、寄生蟲、麻醉用 MS-222），**一律寫給藥途徑或使用方式（藥浴、口服混飼、注射）**，劑量只寫講義有的。**水產用藥有法規與休藥期**，講義沒寫就不要寫。
- **講義的「建議答案」**：`Week1-4.pdf` 的「建議答案」頁是老師給的參考答案，頁面用「講義建議答案」標記，與整理者補充分開。
- **講義夾帶的選擇題**（`生理學P2.pdf`、`skeletal-system.pdf`、`Fish immunity.pdf` 內「正確答案：X」）：**答案是講義寫的**，整理時請**對照同一份講義的正文核對**，題幹或答案有疑義時不要照抄（例如 skeletal-system p.36「魚類脾臟腫大的主要原因不包括哪一項？答 C 環境溫度過高」是否與正文一致，開工時要核對）；沒核對的標「待核對」。
- **兩份生理講義無署名且風格像另外整理過的教材**：寫內容時以講義原文為準，遇到和一般魚類解剖生理認知不同的地方（例如單一說法過於簡化）標「補充：依一般教科書」並提醒使用者，**不要默默改掉**。
- **滲透壓、呼吸與 Bohr／Root effect**：考古幾乎每年有。表格寫「機制→方向→臨床意義」，Bohr（H+／CO2 降低 Hb 對 O2 親和力）與 Root（O2 攜帶量隨 CO2 分壓上升而下降）的定義**分開寫**（學長姐回憶中兩者定義寫得較簡略，不要照抄當官方），並標講義頁碼。
- **口訣只在使用者要求時才做**；**「常考」只在有考古證據時寫**，並寫是哪一年哪一份（見 1.2 的出題模式只能寫「依考古推測」）。
- 使用者是住院醫師，文案中性；繁體中文。

1. **照老師原本的出題方式**：手寫簡答／填空／英文病例／配對／選擇各標題型與配分，保留原題文字與圖；**不要全改寫成小測驗**。
2. 每份考卷前放題型配分表與可展開的**原卷照片**；題目有圖（顯微鏡、蝦組織切片、外觀照片）一定附圖。
3. 照片遮蓋個資後再 `Read` 確認。
4. 答案與詳解是整理者寫的，**非官方**；學長姐手寫答案與批註只當參考並標示；看不清的題照實寫、標「⚠ 待確認」，**不要編造**（例如 2022 蝦病配對題需對照 Keys 表逐題推，推不出來就寫「依講義無法確認」）。
5. 蝦與無脊椎的英文病例題**講義目前沒有對應內容**（見 1.1），詳解只能寫「依題目敘述的判讀依據」，並註明「講義尚未涵蓋，答案為整理者推論」；使用者之後拿到蝦病講義再補。
6. 版面依來源分區（助教／蝦與無脊椎），每區按年份；最後放「重複考點表」（養殖模式、水質、趨性、滲透壓、Bohr／Root、免疫器官、疫苗方式在不同年份重複出現的對照）。

8. **`水產期中考古融合.pdf` 每一頁都要確認是文字、照片還是拼貼**（反芻指引第 11 節的讀檔方法）；文字層亂碼的頁面一律改用看圖。
