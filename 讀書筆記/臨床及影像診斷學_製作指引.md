## 2. 影像學頁面的核心原則：圖要會說話

### 2.1 每張圖的圖說有三層

```
<strong>① 是什麼</strong>：檢查／切面／擺位／序列（例：犬右側位腹部 X 光；鋇劑給藥後 30 分鐘）
② 看什麼：用編號對應圖上的標注（①胃底 ②幽門 ③…），一句話說明正常的樣子
③ 所以呢：這張圖要帶走的重點（診斷意義、和異常的差別、下一步）
```
- **①②來自講義時直接寫；③如果講義沒寫就標「補充」**（講義整理指引的核心原則）。
- 影像描述用固定詞彙，不要憑感覺：X 光 radiopaque／radiolucent、擴大／縮小、位移；超音波 anechoic／hypoechoic／isoechoic／hyperechoic、後方聲影、遠側增強；CT／MRI 的 hyper／hypo／isointense、T1W／T2W／FLAIR／T1+C 對比增強。**第一次出現附中文與英文。**
- 異常影像一律寫：**位置、大小、形狀、邊界、密度（或回聲、訊號）、數量、對周圍的影響**。

### 2.2 標注：哪些要標、怎麼標

> **2026-10-29 使用者要求：標注要能切換顯示／隱藏，原圖拿來自我測驗。** 做法（已實作，範例頁 `week03_X光學基礎.html`）：
> - 原圖先裁成只剩影像本體，存成 `xx_c.jpg`（**這就是隱藏標注時顯示的原圖**；整頁投影片原檔 `xx.png` 保留不刪），標注畫在 `xx_c_a.jpg`，規格 `xx_c.json`。
> - `annotate_figure.py html` 會輸出 `<div class="figure anno" data-orig=… data-anno=…>`，圖例 `<ul class="anno-legend">`。`assets/nav.js` 偵測到 `.figure.anno` 才載入 `assets/anno.js`：每張圖的圖說開頭一顆「隱藏／顯示標注」按鈕（不蓋住影像），右下角一顆「隱藏全部標注（自我測驗）」；隱藏時換原圖、收起圖例、顯示「先自己找出 N 個標注點」；設定記在 localStorage。
> - 圖說三層改用【是什麼】【看什麼】【所以呢】，不要用 ①②③（和標注編號衝突）。
> - 不確定的圖不標，只改圖說並寫明原因（例：p.30 講義沒說哪張是標準擺位）。


| 情況 | 做法 |
|---|---|
| 講義的圖本來就有箭頭、編號 | **保留**，在圖說裡把講義的編號翻成中文（例：講義標號 3＝胃底）。可以另外取沒有標注的原圖來自己標，兩張並排 |
| 講義的圖沒有標注，但文字或圖說指出了結構 | 用 `annotate_figure.py` 補編號、箭頭、框；**只標講義文字或老師標號明確支持的結構** |
| 要標但你不確定位置或結構 | **不要標**。寫「講義未標示」，或問使用者；不確定的標「推測」。**不可以為了圖面好看亂指** |
| 正常 vs 異常 | 兩張並排（`<div class="grid-2">`），標注用同樣的編號與顏色，方便對照 |
| 影像方位 | 圖上或圖說要有：側位（左／右）、VD／DV、頭側在哪邊；超音波探頭位置與方位標記；CT／MRI 的平面（transverse／sagittal／dorsal）與序列、窗寬窗位 |

- 標注顏色：灰階影像用黃色（預設）或青色；一張圖用一種顏色、編號依「由近到遠、由大到小」的判讀順序。
- **標完一定要用 `Read` 看過輸出圖**，確認箭頭指到對的位置、編號沒蓋住病變、字看得清楚；不準就改規格重畫。
- 標注圖的 `figure-source` 固定寫「來源：課程講義 p.N（箭頭與編號為整理者標注）」，工具會自動產生。
- 圖旁的圖例用編號清單（工具自動產生 ① ② ③…），不要把標注文字燒在圖上（中文小字在縮圖上看不清楚，也不能搜尋）。

### 2.3 截圖一定要放：取圖流程與品質

**每個影像概念至少一張圖**；沒有圖的章節要補圖，不要只寫文字。取圖優先順序：

1. **講義 PDF 的內嵌原圖**（最清楚，例如消化道講義 p.46 的 X 光原圖是 2033×978，整頁縮圖只剩 884×424）→ `pdf_figures.py list` 看有哪些，`embedded` 取出。
2. **講義高 dpi 裁切**（要保留老師的箭頭與編號，或圖是向量／拼貼）→ `pdf_figures.py crop`。
3. 整頁輸出（`DVM-note/_scripts/export_slides_jpg.py`，最寬 1300 px）：只在需要完整的教學脈絡（標題＋照片＋說明文字）時用。
4. 商業教科書：**只能本機**，見第 3 節。

**流程（每張要標注的圖）**
```bash
T=讀書筆記/scripts/imaging_tools
# 1 取圖
./.venv/bin/python $T/pdf_figures.py list "<講義.pdf>" <頁碼>
./.venv/bin/python $T/pdf_figures.py embedded "<講義.pdf>" <頁碼> DVM-note/大四上/獸醫臨床及影像診斷學/img/<主題>/ --prefix <前綴>
# 2 疊座標格線，用 Read 看圖決定標注位置（座標是圖寬圖高的比例）
./.venv/bin/python $T/annotate_figure.py grid <圖> <scratchpad>/grid.png
# 3 寫規格 JSON（範例：$T/範例/標注規格.json），畫圖，再用 Read 看結果
./.venv/bin/python $T/annotate_figure.py draw <規格.json>
# 4 產生含圖例的 <figure> HTML，貼進頁面
./.venv/bin/python $T/annotate_figure.py html <規格.json> --src-prefix img/<主題>/
```
- 原圖與規格 JSON 放在 `img/<主題>/`（原圖 `xx.jpg`、標注圖 `xx_a.jpg`、規格 `xx.json`），之後要改只改 JSON 重畫。
- 圖片大小：寬度 ≤ 1600 px、JPEG 品質 85–90；單張盡量 < 400 KB。現有 `img/` 已約 99 MB（脊椎影像學 37 MB、CT／MRI 17 MB），**不要無限制加大圖**；一份講義用不到的頁不要匯出；整頁圖用 1300 px 版本即可。
- 站上已有「點圖放大」（`nav.js`，鍵盤左右切換）：放大看到的是整張圖，所以標注要燒在圖上；不想被放大的圖加 `data-no-zoom`。

### 2.4 一張圖怎麼配合文字：判讀頁的固定骨架

影像章節（X 光、超音波、CT／MRI 的各器官）建議照這個順序寫，每一步都有圖：

1. **檢查品質與擺位**（曝光、擺位是否標準、方向標記）。
2. **正常解剖**（標注圖＋圖例；超音波要有標準切面與探頭位置）。
3. **異常的描述方式**（用 2.1 的固定詞彙；表格：影像表現 → 代表什麼）。
4. **常見疾病的影像特徵**（正常 vs 異常並排、標出病變）。
5. **鑑別診斷與下一步檢查**（講義沒寫的標「補充」）。
6. **陷阱**（偽像、正常變異、擺位造成的假象——超音波偽像、X 光的 Chevron effect 之類，使用者特別在意）。
7. 練習題（見 2.6）。

### 2.5 互動元件（空間或時間概念用）

已有範例可參考（頁面專屬 `<style>`／`<script>` 放在 `</main></div>` 之後、`showSection` 腳本之前，用 IIFE 包起來，顏色用 `var(--accent)` 並處理 `html[data-theme="dark"]`）：
- `week06` 鋇劑造影時間軸（自繪 SVG，點時間點看各段腸道）
- `week07` X 光角度與影像長度、牙周 PD 判定
- `week02`、`week04` 各有一個自繪 SVG

適合做互動的：成像原理（探頭角度、頻率與解析度／穿透力的取捨）、時間序列（造影）、分級判定、切面方位。**手繪 SVG 要標「示意，非解剖比例」**，並用無頭 Chrome 截圖看過。

### 2.6 練習題與看圖題

- 一般題照講義整理指引（12–15 題，答案收在 `quiz-reveal`，含 2–3 題臨床情境）。
- **看圖題**（影像學最重要的題型）：題目放**未標注的圖**，問「這是什麼檢查／切面？哪裡異常？最可能的診斷？下一步？」；答案區放**標注圖**與判讀要點。寫在頁面的 `quiz-item` 裡，圖用 `figure`。
- **自我測驗引擎（`quiz.js`）目前只支援純文字**，沒有圖片欄位。要做影診自我測驗且要看圖題，需先擴充引擎（題目物件加 `img`、解析加 `aimg`），**擴充後務必用豬病學、禽病學題庫回歸測試**（`quiz_check.sh`，cards＝clicked＝exp）。這是較大的改動，**先問使用者要不要做**。

## 5. 新頁面流程（以「物理檢查」為例；影像講義照 2.3–2.4 加強圖）

1. 講義轉 md（`handout_to_md.py`）；縮圖總覽**逐張看完**。影診講義是簡報、幾乎每頁都是圖，**大綱依圖的教學脈絡切節**（講義整理指引第 3 節），不是只看文字。
2. 先列「要放的圖清單」：每個概念至少一張；用 `pdf_figures.py` 取原圖；需要標注的在 JSON 規格裡寫好編號與圖例。

## 7. 影診的特別注意

- **疾病與解剖名稱**：「中文（English）」；縮寫第一次出現要展開（CT、MRI、FLAIR、VD、DV、BCS、PD…）。
- **藥物／對比劑**：只要寫到（鋇劑、碘劑、釓劑、鎮靜或麻醉藥），一定寫給藥途徑（PO／IV／灌腸／局部…），劑量只寫講義有的。
- **擺位與方向用語**很容易搞混（右側位 vs 右側躺、VD vs DV、頭側 cranial／尾側 caudal／背側 dorsal／腹側 ventral／吻側 rostral）：每章第一次出現就用一張圖或表講清楚。
- **偽像與陷阱**是考點也是臨床重點，每個影像模式都要有一節。
- **講義與一般教科書說法不同的地方**照講義寫並註明（消化道頁已有一例：講義把幽門狹窄列在逆流原因）。
- **安全與輻射防護**、鎮靜麻醉風險（CT／MRI）屬臨床重點，講義有就寫。
