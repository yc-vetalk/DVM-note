### 2.1 講義 PDF 壓縮放進網站

```bash
S="$HOME/Library/Mobile Documents/com~apple~CloudDocs/Desktop/NTU/大四上/反芻動物疾病學"
O=DVM-note/大四上/反芻動物疾病學/pdf; mkdir -p $O
gs -q -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook -dNOPAUSE -dBATCH -sOutputFile="$O/仔牛疾病.pdf" "$S/3_仔牛疾病講義.pdf"
```
- 網站 PDF 用中文主題名（側欄標題會顯示）。可以多個 `&` 平行跑再 `wait`。
- 禽病學 12 份講義（含課表）從約 86 MB 壓到 54 MB。**不要用 PyMuPDF 的 rewrite_images**（會弄壞投影片背景）。
- 老師講義可公開（使用者已確認，禽病學、豬病學都已公開）。新科目若不確定，先問。

### 2.2 講義轉 md（每份講義都做，下次讀講義先讀 md）

```bash
./.venv/bin/python 讀書筆記/scripts/course_tools/handout_to_md.py 讀書筆記/講義文字/反芻動物疾病學 DVM-note/大四上/反芻動物疾病學/pdf \
  "$S/3_仔牛疾病講義.pdf|03_仔牛疾病|仔牛疾病" "$S/1_消化生理講義.pdf|01_消化生理|消化生理"
```
- 第三個欄位要和 2.1 的網站 PDF 檔名一致（【含圖】標記會指向它）。
- **使用者的規則：有圖的頁面一定要標記，讀到時回看原 PDF**。md 只有文字，不能當成完整講義。
- 看完縮圖後，對重要的圖片頁在 md 該頁加一行 `【看圖補記】……`（禽病學 IBD、CIA、REO 有範例），下次就不用再看圖。

### 2.3 頁碼必須對得上

`p.N` 一律指 **PDF 第 N 頁**（投影片頁尾的頁碼通常就是第 N 頁，抽一兩頁確認：`pymupdf` 讀 `d[N-1].get_text()` 看頁尾數字）。寫筆記時圖說、footer、正文引用都用這個頁碼，側欄才會跳到對的頁。

## 3. 新頁面的做法（以「仔牛疾病」為例）

1. 讀講義 md 全文；做縮圖 `pdf_contact_sheet.py` 輸出到 scratchpad，**逐張 Read 看完每一頁**。
2. 定大綱（講義整理指引第 3 節）；挑要放的圖，`export_slides_jpg.py ... --pages … --prefix calf` 輸出到 `img/week03_仔牛疾病/`。
3. 在 scratchpad 寫 `.src`（複製 `範例_傳染性華氏囊病.src` 改）：
   - `@@meta dir=DVM-note/大四上/反芻動物疾病學`、`template=` 用同資料夾已有側欄的頁（若都沒有側欄，腳本會自動插入）。
   - 第 1 節固定：大方向（是什麼／為什麼重要／重點連結／容易混淆／考試可能怎麼問（推測））＋ lv-legend ＋「補充說明」提示框 ＋ 主線 flow ＋ 講義 Summary（若有）。
   - 每節：`section-desc`、h3＋lv 標籤、表格優先、圖插在對應段落後、`note-footer` 寫講義頁碼。
   - 最後三節：鑑別比較、考試方向（推測）、練習題 12–15 題（含 2 題臨床情境，答案收在 `<details class="quiz-reveal">`）。
4. `python3 讀書筆記/scripts/course_tools/assemble_page.py <src>`，看輸出的 `unused` 清單，沒用到的圖檔刪掉或補進頁面。
5. **跨講義引用要手動改 href**（例如在仔牛頁寫「消化生理講義 p.12」，腳本會連到仔牛的 PDF；改成 `pdf/消化生理.pdf#page=12`）。
6. 驗證：`verify_page.py`、`check.sh`（bad=0、err 空白）。
7. 站台整合：科目 `index.html` door、`assets/nav-data.js` desc、`search-index.js`（每節一筆，可從頁面 section 自動產生，見下）、頂層 `index.html` 若有科目 topics 也更新。共用檔讀改寫在同一次 Python 執行內完成、用 assert 確認錨點唯一，改完 `node -c`。

> search-index 自動產生的做法（禽病學用過）：從頁面抓每個 `section` 的 `<h2>/<h3>` 當 keywords、`section-desc` 當 snippet、`SECTION_NAMES` 當 sectionName，插在同科目最後一筆之後。

## 4. 國考題（獸醫傳染病學已有反芻題）

照進階指引第 3 節，在 `species.py` 新增 `'反芻動物疾病學'`。禽病學學到的：

- **加 `'answer_group': True`**：很多舊題題幹不寫病名（「下列何種疾病…」），病名在選項裡。開了這個選項，題幹分不出來時會用**正解選項**歸類（禽病學「其他」組從 175 題降到 13 題）。這個選項只影響開啟的科目，豬病學輸出不變（改前先備份 `國考專區/課程/豬病學/國考題彙整.md`，改後 `diff` 確認）。
- 舊病名也要放進正規式（禽病學例：可利查＝傳染性鼻炎、里奧＝呼腸孤、白冠病＝住白血球蟲、雞瘟＝HPAI）。反芻可能有：牛流行熱、牛結節疹、牛疫、羊痘、副結核、焦蟲、梨形蟲、牛瘟、炭疽、氣腫疽、惡性水腫、Q 熱、布氏桿菌、口蹄疫…
- 分組先符合先歸類，**順序會影響結果**（禽病學曾把腫頭症的題目分進新城病，因為題幹有「副黏液」，後來把禽痘／肺病毒組移到新城病前面）。
- 分組依**課程講義**，不要硬套教科書分類；先給使用者看各組題數再寫詳解。
- `strong` 關鍵字要避免誤收（例：「蛋」會抓到「蛋白」，禽病學改用「產蛋|種蛋|蛋殼」）。反芻要小心「牛」出現在其他科題目的選項或題幹（例如「牛奶」、「牛結核」與人畜共通題）。
- 產生國考 HTML 頁後，`md_to_html.py` 的副標題會寫「含詳解」，若詳解還沒寫完，用 `sed` 改成實際狀態。

## 5. 國考逐選項詳解（每章一個檔）

- 放 `國考專區/課程/反芻動物疾病學/詳解/s<NN>_<主題>.txt`（`s*.txt` 都會被讀），一行一題 `題號|總評|A|B|C|D`。
- **自我測驗引用國考題時，那一題一定要有詳解**，否則 `build_quiz.py` 會直接報錯（`'NoneType' object has no attribute 'split'`）。報錯時找最後加進 spec 但還沒寫詳解的題號。
- 別名 `題號|=另一題號` 只能用在**四個選項文字完全相同**的題；禽病學踩過的雷：
  - 選項「A型、D型…」與「A、D…」被判為不同（normalize 後長度 ≤ 3 不做模糊比對）。
  - 題幹相同但某一個選項換了（113-2#23 vs 97-1#33），不能用別名。
  - 印出 `ALIAS MISMATCH` 就改寫成完整一行。
- 官方答案缺的題：總評寫「（本份試卷官方答案缺，依知識判斷為 X）」；**不確定就寫不確定**（禽病學 115-2#18 寫了「建議對照防檢署公告」）。
- **官方答案和講義不一致時，照官方答案作答，但在總評寫出講義的說法**（禽病學 98-1#43：官方 1–3 週 vs 講義最早 5 週）。新舊分類不同也要註明（環狀病毒科新舊分類）。
- 只收**有講義的主題**的題目；沒有講義的主題（禽病學的腺病毒、禽腦脊髓炎）不要硬寫進自我測驗，跟使用者說等講義。
- 詳解寫完，重產國考頁：`TPL=… md_to_html.py …`（進階指引第 5 節）並更新科目 index、國考 index、search-index 的「詳解」描述。

1. 複製 `DVM-note/大四上/禽病學/自我測驗/` 整個資料夾到反芻，`rm data/*.js`，`sed` 把「禽病學」換成「反芻動物疾病學」，`quiz.js` 的 key 改成 `ruminant-quiz-v1`。


## 9. 補充筆記（黃框 Note）的工作流程

使用者學習時會**截圖追問**（「這是什麼？」「怎麼算？」「為什麼？」「幫我整理在一起」），流程固定：

1. **先在對話裡解釋**：用小標、表格、條列，分清楚「講義寫的」與「我補充的」；講義沒寫的標「補充」，不確定的標「推測」或「⚠ 待確認」，**不要編造**（例如 methionine 為什麼加在輸液裡，講義沒說，就直接說講義沒說、列出可能性並標推測）。
2. **解釋完問一句「要不要加進筆記」**（使用者通常回「加入」）。使用者指定放哪裡時照辦（當節筆記、國考統整表格、專題頁、哪一節）。
3. 加進筆記的格式（記憶 `feedback_qa_note_layout.md`）：`<details class="alert alert-warn study-note" style="font-size:.9em;line-height:1.65;margin:1rem 0"><summary style="cursor:pointer;font-weight:700;color:var(--amber-700)">讀書補充Note - 標題</summary>` ，裡面小標＋條列＋三層編號，每個注記一個黃框 toggle、預設收起、可以很長。
4. 插入位置：該節的 `note-footer` 之前，或相關 Note 之前；**用 Python 在同一次執行內讀、改、寫**，`assert` 錨點唯一，且 `assert '新標題' not in s`（避免重複加）。
5. 加完：`verify_page.py`、`_worklog.md`、`build_changelog.py`；全文搜尋索引等 commit 時 hook 重建。
6. **不要自己加口訣**（記憶 `feedback_mnemonic_on_request.md`），使用者要求時才做。
7. 計算題要拆解單位（例如 mL/kg/hr 換算），並註明哪些數字是講義、哪些是共筆、哪些是我自己算的示意。
8. 如果加的內容和同頁既有說法衝突，先告訴使用者（CLAUDE.md 規則 4），不要直接覆蓋。

**更改國考或比較表的陳述時**：先查證本站題庫（不要說「國考沒考」，要說「本站收錄的獸醫傳染病學沒有考，其他考科尚未收錄」）。

## 11. 期中考古頁（依老師分類）與考古自我測驗

**頁面結構（`期中考古.html`，模板複製專題頁後改 breadcrumb 與 `data-current="大四"`，移除舊搜尋框）**

## 12. 版面與驗證的實務教訓

- **scratchpad 會消失**：之前的 `.src`、腳本、截圖在對話結束後可能不見（`nut.src` 就不見了）。重要內容直接以 HTML 為準；要重建頁面前先確認 `.src` 還在，否則從 HTML 取回補充 Note。
- 用 Python 改共用檔（`search-index.js`、`nav-data.js`、各 `index.html`）時：讀、改、寫同一次執行，`assert` 錨點唯一；改完 `node -c`；刪除或改名頁面要同步刪 search-index 舊條目與頁面內舊連結。
- **圖像或 SVG 一定要實際看**：用無頭 Chrome 截圖後 Read：
  `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --screenshot=out.png --window-size=1280,2400 "file:///…/頁面.html"`。（手繪 SVG 位置圖——例如 ping 位置圖——要標「示意，非解剖比例」。）
- 連結檢查：用 Python 掃 `href`／`src`，確認檔案存在、`#錨點` 在目標頁有 `id=`。

- `verify_page.py` 通過不代表版面對；有新表格或 SVG 就截圖看。
- 無頭 Chrome 在 `check.sh` 之類腳本會在頁面資料夾寫暫存檔（`_t.html`），多頁**依序**跑、不要平行。
