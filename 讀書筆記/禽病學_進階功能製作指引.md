## 2. 講義頁面產生器（豬病學版，禽病學要複製後改路徑）

位置：`讀書筆記/scripts/swine_page_builder/`。這套做出來的頁面比手寫 HTML 多了：自動目錄、右側 **PDF 對照側欄**（點頁面上任何「p.N」就在側欄開啟講義對應頁）、國考題卡片、練習題、搜尋索引條目。

### 2.1 檔案

| 檔案 | 用途 |
|---|---|
| `build.py` | `python3 build.py 頁.src tail.js`：把 `.src` 內容檔產生成完整 HTML，同時產生 `頁.idx.js`（search-index 條目） |
| `範例_week04_豬痘.src` | **內容檔格式範例**（最重要，照它改）：meta 行、`@@` 分節行、`[[F:頁碼\|圖說]]` 圖片佔位、`X\|` 國考題卡片、`E\|` 問答題、`Q\|` 練習題、`Q\|vig\|` 臨床情境題 |
| `integrate.py` | 把頁面接進站台：科目 `index.html` 的 door、頂層 `index.html` 卡片、`nav-data.js` desc、`search-index.js`。**`SUB`、`PAGES` 清單寫死豬病學**，禽病學要複製成新檔並改 `SUB = ROOT + '大四上/禽病學/'`、`PAGES`、卡片標題「豬病學」→「禽病學」 |
| `check.sh 頁面.html` | 無頭 Chrome 檢查圖片是否載入、有幾個可釘選段落、JS 有沒有錯誤。輸出 `R imgs=N bad=0 pins=N err=`（bad=0、err 空白才算過） |
| `crops.py`、`exam06.py` | 圖片裁切、國考卡片 HTML 產生，被 build.py 使用 |
| `tail.js`、`pdfpanel.css`、`pdfpanel.html` | 頁尾腳本與 PDF 側欄元件 |

### 2.2 要注意

- `build.py` 的模板是「沿用 week02 模板的 header／toc／script」，**路徑深度是 `大四上/<科目>/`（用 `../../`）**；禽病學同深度，可直接用。
- 圖片：用 `DVM-note/_scripts/export_slides_jpg.py`（整頁匯出 JPG）與 `pdf_contact_sheet.py`（每 12 頁拼一張縮圖總覽，用來掃過整份講義）。**每一頁講義都要看過**。
- 講義 PDF 要放 `pdf/<名稱>.pdf` 給側欄用。原檔太大時用 Ghostscript 壓縮：`gs -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook -dNOPAUSE -dBATCH -sOutputFile=out.pdf in.pdf`（不要用 PyMuPDF 的 rewrite_images，會弄壞投影片背景）。
- **講義 PDF 可以公開**：使用者已說明老師同意公開；repo 是公開的（GitHub Pages）。
- 禽病學已有手寫頁面時，不必改用產生器重做；產生器是給「還沒做的週」或使用者要求升級時用。

## 3. 國考題庫（考選部公開試題）

### 3.1 已有的資料

- 來源：考選部「考畢試題查詢平台」，專技高考獸醫師「獸醫傳染病學」民國 97–115 年共 32 份、2560 題單選，含官方答案。
- 產出（豬病學版已完成）：`讀書筆記/國考題庫/獸醫傳染病學/YYY-N.md`（32 份完整試卷）、`豬病學_國考題彙整.md`（依疾病分組的豬題）、`原始試卷/`（原始 PDF）。`讀書筆記/` 自 2026-10-22 起進公開 git（使用者決定，含指南圖片與期刊原文 PDF）。
- 2560 題裡**本來就包含禽、牛羊、魚、犬貓等所有題目**，禽病學不用再抓，只要「篩選」。

### 3.2 做禽病學國考題彙整

1. 編輯 `讀書筆記/scripts/exam_scraper/species.py`：在 `SPECIES` 新增 `'禽病學': {...}`，格式照 `'豬病學'`：
   - `strong`：題幹關鍵字（雞、鴨、鵝、火雞、禽、鳥、新城病、馬立克、禽流感、傳染性支氣管炎、傳染性法氏囊、禽白血病、禽痘、鵪鶉、鴿、Newcastle、Marek、avian…）。
   - `weak`：只比對選項的關鍵字。
   - `diseases`：`[(分組名, 正規式), …]`，**先符合先歸類**，例如：新城病／禽流感（呼吸道病毒）、馬立克病與白血病腫瘤病毒、傳染性法氏囊與雞貧血、細菌（沙門氏、大腸桿菌、黴漿菌、巴氏桿菌、禽結核…）、寄生蟲與原蟲（球蟲、組織滴蟲…）、其他。
2. 在工作資料夾執行（需要 `meta.json`、`answers.json`、`parsed_old.json`、`pdf/`、`ans/`，已備好在 `讀書筆記/scripts/exam_scraper/workdir/`）：
   ```bash
   cd 讀書筆記/scripts/exam_scraper/workdir
   ../../../../.venv/bin/python ../make_md.py ../../../國考題庫
   ```
   會輸出 `讀書筆記/國考題庫/禽病學_國考題彙整.md`（也會重產豬病學與 32 份完整試卷，內容相同）。
3. **先抽查分組結果**：用 `dump_sec.py`（`SUBJECT=禽病學 .venv/bin/python 讀書筆記/scripts/exam_scraper/dump_sec.py N` 印第 N 組題目），看「其他」組有沒有明顯屬於某疾病的題目，回頭補 `species.py` 的正規式再重跑。關鍵字篩選一定有漏／誤收，這是已知限制，頁面上要寫明。

### 3.3 已知的資料問題（不要重蹈）

- **官方答案缺**：100 年第一次、115 年第二次沒有官方答案（考選部答案清冊抓不到）。這兩份的題目答案欄顯示「尚未取得」，`build_quiz.py` 會跳過沒答案的題，除非詳解第一欄有「（本份試卷官方答案缺，依知識判斷為 X）」這句，才會用 X。
- **一律給分**：官方標「#」的題，答案是「一律給分」，沒有單一正解，也會被跳過。
- **試卷更正**：98-2#18、99-2#11 官方有「經試題疑義會議決議更正答案」，已寫在 `make_md.py` 的 `OVERRIDE`；禽病學若遇到類似題，在 `OVERRIDE` 加一筆。
- **含圖題**（約 157 題）：只有文字，題目下方標示原卷頁碼與 PDF 位置；詳解只能依官方答案與題幹推論，要寫明「含圖，請對照原卷」。
- **97–99 年舊試卷版面特殊**：文字與選項位置交錯，已用 `parse5.py`（依座標與標籤配對）處理並逐份驗證 80 題。曾發現 97 年第一次有 4 題因題幹斷行導致選項位移，已修正。若新增解析流程，務必驗證「每份 80 題、每題 4 選項、有答案」。
- 字元：已把康熙部首字（⽣、⼤…）轉成一般字；少數亂碼字元以 □ 顯示，需對照原卷。

## 4. 國考題詳解（逐選項）

### 4.1 格式

詳解放在 `讀書筆記/國考題庫/詳解/`（豬病學）。禽病學請**另開資料夾** `讀書筆記/國考題庫/詳解_禽病學/`，不要混進豬病學。每個 txt 一行一題：

```
題號|總評|A選項說明|B選項說明|C選項說明|D選項說明
```
- 題號格式 `年-梯次#題號`，例如 `98-1#3`（98 年第一次第 3 題；第二次是 `-2`）。
- 共 5 個欄位（總評＋4 個選項），用 `|` 分隔；內容不能含 `|`。
- 重複出現的題可寫 `題號|=另一題號`，**只有兩題的選項順序與內容完全一樣才能用**（程式會比對，不一致會印 `ALIAS MISMATCH`）。
- 答案選項的說明寫「正確：…」或「錯誤（正解）：…」（題幹問「何者錯誤」時，答案選項是錯的那個）。
- 官方答案缺的題，總評寫「…（本份試卷官方答案缺，依知識判斷為 C）」。

### 4.2 品質檢查（做完必跑）

用 `md_to_html.py`（見 5.）會同時驗證並印出：`explained N missing 0 bad [] extra []`。**missing 必須為 0**。另外建議跑兩個自查：
- 每題「（正解）」標記的選項要等於官方答案字母（做過，曾找出一題把 4 個選項寫成 3 個導致位移）。
- 答案選項的說明語氣要與題幹相符（問「何者錯誤」時答案選項不能寫「正確」）。

### 4.3 寫詳解的原則

- 答案以**官方答案**為準；詳解是依知識寫的，不是官方詳解，頁面要寫明。
- 講義沒寫、為了解釋延伸的內容標「補充」；不確定的寫「不確定／建議對照講義」，不要編造。
- 有爭議或一律給分的題要說明為何有爭議。

## 6. 自我測驗（互動練習）

位置：`DVM-note/大四上/豬病學/自我測驗/`（豬病學已完成第 1–7 週）。每章 25–100 題，作答後立即顯示對錯、正解、解析、講義頁碼；錯題自動進錯題本；長章節有「隨機 25 題」。進度與錯題存 localStorage（`swine-quiz-v1`），**只在使用者當下的瀏覽器，不同步**。

### 6.1 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 章節列表與錯題本入口 |
| `quiz.html?c=<章節id>[&m=wrong\|quick]` | 作答頁（引擎在 `quiz.js`，樣式 `quiz.css`） |
| `data/<章節id>.js`、`data/chapters.js` | 題庫資料，**由 build_quiz.py 產生，不要手改** |
| 來源 spec | `讀書筆記/國考題庫/自我測驗/<章節id>.py`（題庫的「原始碼」，改題目改這裡） |

### 6.2 禽病學怎麼做

1. **複製整個 `自我測驗/` 資料夾**到 `DVM-note/大四上/禽病學/自我測驗/`，刪掉 `data/` 內的豬病學題庫，改 `index.html`／`quiz.html` 裡的麵包屑「豬病學」→「禽病學」與標題（兩檔各一處 `<a href="../index.html">豬病學</a>` 與標題文字）。`quiz.js` 內 localStorage key 是 `swine-quiz-v1`，**改成 `poultry-quiz-v1`**，避免與豬病學的紀錄混在一起。
2. 在 `讀書筆記/國考題庫/自我測驗_禽病學/` 為每個章節寫一個 spec（`.py`）。格式：
   ```python
   TITLE = "第 2 週・新城病"
   ORDER = 2.0                    # 章節排序
   GROUPS = [
    ("1. 這是什麼病", "先抓大方向", [
      ('mc', "題幹", ["選項A","選項B","選項C","選項D"], 正解index(0起算), "解析", "p.3"),
      ('tf', "敘述", True, "解析", "p.5"),
    ]),
    ("N. 國考題", "歷屆國考（含詳解）", [ ('x','98-1#3'), ('x','103-2#10') ]),   # 引用國考題庫
   ]
   ```
   - 手寫選擇題的選項**建構時會自動打亂**（確保正解不全在 A）；所以寫的時候可以把正解放第一個。
   - `('x', 'key')` 引用國考題庫的題（含題幹、選項、官方答案、你寫的詳解）；**需要該題有官方答案**（或詳解寫了「依知識判斷為 X」），否則會被跳過並印 `skip (no answer)`。
3. 建構：
   ```bash
   SUBJECT=禽病學 \
   EXPDIR=讀書筆記/國考題庫/詳解_禽病學 \
   SPECDIR=讀書筆記/國考題庫/自我測驗_禽病學 \
   QZOUT=DVM-note/大四上/禽病學/自我測驗/data \
   .venv/bin/python 讀書筆記/scripts/exam_scraper/build_quiz.py
   ```
   會產生 `data/*.js`與 `data/chapters.js`，並印出每章題數。
4. 驗證：用無頭 Chrome 開 `quiz.html?c=<id>` 並程式點選所有選項，確認題數與分數（做法見豬病學做法：在 quiz.html 複本末尾插一段 `<script>` 點擊所有 `.qz-opt`，印標題）。

### 6.3 出題原則（使用者的要求）

- **不限題數，要「涵蓋整份講義內容」**：使用者原本說 10 題不夠，要 20–30 題；後來明確說「不一定是要幾題，就是要你認為可以涵蓋所有內容，把國考題加進去非常好」。
- **順序依章節脈絡**：這是什麼病 → 病原 → 傳播與致病 → 臨床病變 → 診斷 → 防治 → 鑑別 → 國考題。**不看講義直接做，也能從解析了解這章在講什麼**。
- 題目與解析只能依講義內容；講義沒寫的標「補充」。頁碼是約略位置（對應區段），頁面上已有說明。
- 手寫題**要讀完那章講義才寫**，不要憑一般知識。

### 6.4 自我測驗的入口（使用者要求「不要只有一個小連結」）

豬病學做了四處入口，禽病學比照辦理（路徑相對於 `DVM-note/大四上/禽病學/`）：

1. **科目首頁的大卡片**：在 `index.html` 的 `<h2>週次筆記</h2>` **上方**新增一區「練習與複習」（`<h2>練習與複習</h2>` ＋ 一個 `<ul class="hero-doors hero-doors--topics" id="practice-doors">`，放「自我測驗」「歷屆國考題統整」「統整表格」三張 `hero-door` 卡片，照豬病學首頁複製）。
   - **`id="practice-doors"` 一定要加**：`integrate.py` 會用 `<ul class="hero-doors hero-doors--topics">` 重寫週次清單；有 id 的這個 ul 字串不同，不會被覆蓋。複製 `integrate.py` 時，也要確保它是從 `<h2>週次筆記</h2>` **之後**才找這個 ul（豬病學版已改好）。
2. **每章頁面頂端資訊列**：在 `meta-bar` 的「講義 PDF」那格後面加
   `<div class="meta-item"><div class="meta-label">自我測驗</div><div class="meta-value"><a href="自我測驗/quiz.html?c=<章節id>">做題 →</a></div></div>`。
3. **每章頁面最下方的大按鈕**：在最後一個 `<footer class="note-footer">` 前加一個 `<div class="quiz-cta">`（置中淺底區塊，標題「讀完了？用題目檢查一下這章」，棕色圓角按鈕「📝 做這章的自我測驗 →」，下方一行小字）。樣式全用 inline style，原始碼看豬病學任一章節頁。
4. **每章頁面左側目錄**：在 `<nav class="toc">` 的 `</nav>` 前加
   ```html
   <div class="section-label" style="margin-top:8px;">練習</div>
   <a href="自我測驗/quiz.html?c=<章節id>" id="nav-quiz-link"><span class="nav-icon">📝</span> 自我測驗</a>
   ```
   這是開新頁面的連結（不是頁內 `showSection`），沒有「目前位置」高亮是正常的。

- `<章節id>` 必須與 `data/<章節id>.js` 的檔名一致（也就是頁面檔名去掉 `.html`），連結裡的中文要 `urllib.parse.quote`（`quiz.js` 用 `URLSearchParams` 讀，會自動解碼）。
- 這四處是批次用 Python 加進 HTML 的，**做成腳本時要冪等**（已有 `quiz-cta`、`nav-quiz-link`、`meta-label">自我測驗` 就跳過）。
- **如果頁面是用 `.src` ＋ `build.py` 產生的，重新產生會覆蓋這四處**；要永久保留，需把它們加進 `build.py` 的模板或 `.src`（豬病學目前尚未做，只直接改了 HTML）。禽病學手寫頁面不受影響。

### 7.2 讀書補充Note（使用者問問題後加進筆記的注記）

使用者常在讀網頁時問「這是什麼？要背嗎？怎麼理解？」，並要求「加進筆記」。格式（使用者明確喜歡這個版面）：

```html
<details class="alert alert-warn study-note" style="font-size:.9em;line-height:1.65;margin:1rem 0">
  <summary style="cursor:pointer;font-weight:700;color:var(--amber-700)">讀書補充Note - 問題標題</summary>
  <p><strong>先講結論</strong></p>
  <p>…</p>
  <p><strong>1. 這是什麼／怎麼運作</strong></p>
  <ul><li>…</li></ul>
  <p><strong>要不要背</strong></p>
  <ol>
    <li><strong>一定要會（國考出過）</strong><ul><li>…</li></ul></li>
    <li><strong>懂原理就好</strong><ul><li>…</li></ul></li>
    <li><strong>不用背</strong><ul><li>…</li></ul></li>
  </ol>
</details>
```
- **一個問題一個黃框 toggle**，預設收起，標題前綴固定「讀書補充Note - 」；放在**對應段落正下方**。
- 版面：加粗小標＋條列＋「一定要會／懂原理就好／不用背」三層編號；可以很長。
- 講義沒寫的細節標「補充」；「要不要背」是依考古題方向的判斷，要註明「以老師上課為準」。
- 國考相關要寫出年份與陷阱（例如「105 年選項『ApxIII 具有較強溶血性』是錯的」）。

## 9. 使用者偏好與已知雷點

- **身份與文案**：使用者是獸醫系學生、同時是動物醫院的住院醫師；文案中性，不預設「實習生」。

- **藥物一定寫給藥途徑**（PO／IV／IM／SC／外用…）。
- **「國考常考」要有考古題證據**；沒有就不要寫，推測的方向標「推測」。

- 不要同時啟動大量工作；使用者說「整理先到這裡」就停，轉問答模式時直接回答、必要時詢問是否加進筆記。
- 使用者在手機、排隊時也會讀網站：頁面要能在窄螢幕使用，進度紀錄不跨裝置同步（已告知）。

## 11. 換科目時怎麼改（反芻動物學、魚病學、大動物外科學…）

### 11.0 原則：保持彈性，不要硬套

- 這份指引是以「疾病類科目」（豬病學、禽病學）為例寫的。**每個科目、每項功能都由使用者決定要不要做**，不要預設全做；先用一兩句話問清楚這次要做哪幾項、先做哪一章，做完一小塊給使用者看再繼續。
- 工具是「資料檔＋小腳本」：能沿用就沿用，不合適就**只借用能用的部分**，必要時改工具或另寫，不要為了套用工具而扭曲內容。
- 改工具時：**先確認舊科目（豬病學）輸出不變**（做法：改前複製一份輸出，改後重跑再 `diff`），再往下做。

### 11.1 速查：每項功能換科目要改什麼

| 功能 | 能不能直接沿用 | 換科目要改什麼 |
|---|---|---|
| 考前重點收藏、目錄收合 | 完全沿用 | 不用改 |
| 讀書補充Note、統整表格、發佈與日誌流程 | 完全沿用 | 統整表格只是在同一頁加新的編號節與列 |
| 自我測驗引擎 | 沿用，改小地方 | 複製 `自我測驗/` 資料夾；改 `index.html`／`quiz.html` 的麵包屑與標題；`quiz.js` 的 localStorage key（例如 `ruminant-quiz-v1`、`lgsurgery-quiz-v1`）；題庫另寫 spec |
| 自我測驗的題型 | **只支援純文字的選擇題與是非題** | 要圖片題、排序題、配對題、填空題，需要擴充 `quiz.js`（見 11.3） |
| 國考題庫（獸醫傳染病學科目） | 沿用，改設定 | 在 `species.py` 新增一組關鍵字與疾病分組（反芻、魚都適用） |
| 國考題庫（其他科目） | 資料已備好，要再下載與解析 | 見 11.3 |
| 國考頁、詳解 | 沿用格式 | 詳解資料夾另開（`詳解_<科目>/`），不要混進其他科目 |
| 講義頁面產生器 | 要複製後改路徑 | `integrate.py` 的 `SUB`、`PAGES`、卡片標題；疾病類頁面骨架（病原→致病→臨床→診斷→防治）不適用時，用手寫 HTML 或改 `.src` 的分節 |
| 頁面內容與題目 | 必須重寫 | 一定要讀完該科講義，不要憑一般知識，更不要照搬別科的內容 |

### 11.3 大動物外科學（手術類／技術類科目）

這類科目和疾病類差異大，先與使用者確認要做哪些，再決定工具怎麼改。

**1. 國考題來源要另外下載**
- 外科的題目多在「獸醫普通疾病學」科目（另有「獸醫實驗診斷學」等）。`workdir/rows_all.json` **已經存了六個科目、各 32 份試卷的下載連結**（獸醫病理學、獸醫藥理學、獸醫實驗診斷學、獸醫普通疾病學、獸醫傳染病學、獸醫公共衛生學），不用重查詢。
- 下載與解析（在 `workdir/` 執行；範例以獸醫普通疾病學為例）：
  ```python
  import json,subprocess,os
  B='https://wwwq.moex.gov.tw/exam/'
  rows=json.load(open('rows_all.json'))
  for exam,cat,subj,links in rows:
      if subj!='獸醫普通疾病學' or not links: continue
      q=dict(p.split('=') for p in links[0].split('?')[1].split('&'))
      fn=f"pdf/{q['code']}_{q['c']}_{q['s']}_gen.pdf"
      if not os.path.exists(fn): subprocess.run(['curl','-s','-o',fn,B+links[0]])
      # 答案清冊：整份試卷共用，用 t=A（100 年起才有；97–99 年答案內嵌在試題 PDF）
      af=f"ans/{q['code']}_{q['c']}_55.pdf"
      if not os.path.exists(af): subprocess.run(['curl','-s','-o',af,B+f"wHandExamQandA_File.ashx?t=A&code={q['code']}&c={q['c']}&s=55&q=1"])
  ```
  再參照 `answers.py`（`SUBJ=獸醫普通疾病學` 指定科目）與 `make_md.py`、`parse.py`、`parse5.py`；**`make_md.py` 目前用檔名後綴 `_inf.pdf` 與 `meta.json` 只收傳染病學，要另寫 meta 並把後綴與科目名稱參數化**。解析後務必驗證每份題數、每題 4 選項、有答案（97–99 年舊試卷版面特殊，見 3.3）。
- 篩選外科題：關鍵字例：骨折、關節、疝氣、腹部手術、胃扭轉、牛皺胃、剖腹產、去勢、縫合、麻醉、跛行、蹄病…；用手術部位或疾病分組。
- **先問使用者**：外科考題量與重要性是否值得再下載一次；有些外科內容（操作、器械、實習）國考題很少，不必硬做彙整。

**2. 自我測驗要改題型與排序**
- 排序原則：疾病類是「這是什麼病 → 病原 → … → 防治」；手術類改成「適應症 → 保定與麻醉 → 器械與準備 → 手術步驟 → 術後照護 → 併發症」或依講義的操作流程。
- 手術類常需要：**看圖題**（器械辨識、解剖位置、縫合法）、**步驟排序題**、**配對題**。引擎現況不支援，擴充做法（`quiz.js` 的 `renderQuiz`）：
  - 圖片：題目物件加 `img: 'img/xxx.jpg'`，在題幹下方插入 `<img>`。
  - 排序：新增題型 `'order'`（給一組打亂的步驟，使用者點選順序，對照正確順序）。
  - 配對：新增題型 `'match'`。
  - 擴充後**一定要用豬病學的題庫回歸測試**（無頭 Chrome 點選所有選項，確認題數與分數與擴充前一樣）。
- 若只要簡單的文字選擇題與是非題，不需要擴充。

**3. 頁面內容**
- 大動物外科是 16 週、課堂＋實習，圖片多（手術照片、器械圖），已有既有頁面（`DVM-note/大四上/大動物外科手術及實習/`）；以該資料夾與 `講義整理指引.md` 的技術類範本為準（例如 COHAT 口腔評估頁），**不要套疾病類骨架**。
- 要升級既有頁面時，只加「自我測驗」入口與補充Note，不重寫內容，除非使用者要求。

### 11.6 什麼時候不要硬套

- 內容少、章節少的科目：直接手寫頁面，不需要產生器與題庫。
- 使用者只要「某一章的簡單練習」：寫一份小 spec 就好，不必先做國考彙整與詳解。
- 國考題很少涉及的主題：自我測驗以講義內容為主，不要硬塞國考題。
- 不確定時，**先問使用者、先做最小的一塊**，確認方向後再擴大。
